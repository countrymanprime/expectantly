# API reference

Everything public in `Expectantly` today. Generated by reading the source directly (there is no
generated API doc tooling yet — see [`flaws-and-enhancements.md`](flaws-and-enhancements.md)).

## `Expectantly.Expect` (static)

| Member | Signature | Notes |
|---|---|---|
| `That<T>` | `ObjectAssertions<T> That<T>(T actual, string? because = null, params object[] becauseArgs)` | Wraps a concrete value. |
| `That<T>` | `ObjectAssertions<T> That<T>(Func<T> actualFactory, string? because = null, params object[] becauseArgs)` | Invokes `actualFactory` exactly once. Throws `ArgumentNullException` if `actualFactory` is `null`. |

## `Expectantly.ObjectAssertions<TActual>`

Implements `IAssertion<TActual>`. Constructed only via `Expect.That`.

| Member | Type/Signature | Behavior |
|---|---|---|
| `Actual` | `TActual` | The value under test. |
| `Context` | `IAssertionContext` | Metadata for message formatting. |
| `Is(TActual expected)` | `AndConstraint<ObjectAssertions<TActual>>` | Throws `InvalidOperationException` unless `Equals(Actual, expected)`. |
| `IsNot(TActual unexpected)` | `AndConstraint<ObjectAssertions<TActual>>` | Throws unless `Actual` differs from `unexpected` by `Equals`. |
| `IsNull()` | `AndConstraint<ObjectAssertions<TActual>>` | Throws unless `Actual is null`. |
| `IsNotNull()` | `AndConstraint<ObjectAssertions<TActual>>` | Throws unless `Actual is not null`. |
| `IsSameAs(TActual instance)` | `AndConstraint<ObjectAssertions<TActual>>` | Throws unless `ReferenceEquals(Actual, instance)`. **Caveat for value types** — see flaws doc. |
| `IsAssignableTo<TExpected>()` | `AndConstraint<ObjectAssertions<TActual>>` | Throws unless `Actual is TExpected`. |
| `IsTrue()` | `AndConstraint<ObjectAssertions<TActual>>` | Throws unless `Actual` is `bool` and `true`. |
| `IsFalse()` | `AndConstraint<ObjectAssertions<TActual>>` | Throws unless `Actual` is `bool` and `false`. |

All failure messages are `InvalidOperationException`s built from a private `Display(object?)` helper
(`<null>` for null, `<value>` otherwise) plus `Context.FormatBecauseClause()`.

## `Expectantly.AndConstraint<TSelf>`

Implements `IAndConstraint<TSelf>`.

| Member | Type | Notes |
|---|---|---|
| `And` | `TSelf` | Returns the wrapped assertion object, enabling `.Is(x).And.IsNotNull()`. |

## `Expectantly.Abstractions.IAssertionContext`

| Member | Type/Signature | Notes |
|---|---|---|
| `Because` | `string?` | Raw, unformatted reason text. |
| `BecauseArgs` | `IReadOnlyList<object?>` | Format arguments for `Because`. |
| `FormatBecauseClause()` | `string` | Returns `""` or `" because <formatted reason>"`. |

## Internal (not part of the public contract)

- `Expectantly.Internal.AssertionContext` — the only `IAssertionContext` implementation. Formats
  `Because` with `string.Format(CultureInfo.InvariantCulture, ...)` when `BecauseArgs` is non-empty.
